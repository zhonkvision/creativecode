## 1. System Overview

**CreativeCode.my** is a high-performance **Living Visual DNA Engine** and experimental generative art laboratory. Rather than a static portfolio or catalog, it provides a bidirectional computational feedback loop between visual taste archetypes, procedural mathematics, and interactive web graphics.

The platform translates raw visual references (tactical CRT neurology HUDs, 1984 phosphor raster displays, arcade coin-ops, silicon wafer defect maps, and astronomical spectrograms) into formal JSON Visual DNA manifests. These manifests drive 32 interactive canvas and shader engines with real-time parameter mutation, genetic cross-breeding, CRT optics post-processing, and procedural Web Audio synthesis.

## 5. Live Mutation Workbench & Studio Architecture

When clicking **INSPECT SPECIMEN** on any artwork, the laboratory opens the **Mutation Studio Modal**:

1. **Active Viewport**: Renders the specimen in high-resolution canvas or sandboxed iframe mode.
2. **Dynamic Parameter Deck**: Automatically constructs range sliders, select dropdowns, text fields, and mechanical toggles from the specimen's `project.json` parameter schema.
3. **Bi-Directional `DNA_MUTATION` Protocol**:
   ```javascript
   // Parent Workbench → Active Specimen Iframe
   iframe.contentWindow.postMessage({
     type: 'DNA_MUTATION',
     parameters: { speed: 1.5, intensity: 1.2, show_gui: true },
     enabled: { bloom: true, sunrays: false }
   }, '*');
   ```
4. **Hardware Capture Suite**:
   - **Lossless PNG / JPG Snapshots**: Exports clean viewport frames without UI elements.
   - **60 FPS MP4 Stream Recorder**: Hardware-accelerated `MediaRecorder` stream recording at 16 Mbps bitrate.
   - **Looping GIF Recorder**: High-speed frame capture with custom LZW canvas GIF encoding.
   - **Share & Deep Linking**: Generates persistent URLs (`/experiment/:slug`) with encoded parameter state.

## 7. Local Development & Deployment

### Quick Start

```bash
# 1. Clone repository
git clone https://github.com/zhonkvision/creativecode.git
cd 11-creativcode.my

# 2. Rebuild catalog (registers any new project.json files)
npm run build

# 3. Start local development server
npm run dev
# Or with Python:
# python3 -m http.server 8080
```

Open `http://localhost:3000` in your browser.

### Production Build & Deployment

The repository is configured for instantaneous deployment on **Vercel**:

```bash
# Build & deploy to production
npx --yes vercel --prod --yes
```
