# Contributing to Grainrad Bulk Exporter

Thanks for your interest in contributing! This tool is designed to help artists simplify their workflow.

## 🤝 Code of Conduct

1. **Respect Grainrad.com:** This tool relies on the generosity of Grainrad's free service. Do not submit code that:
    - Bypasses rate limits aggressively.
    - Spams the server with parallel requests (keep it sequential).
    - Removes attribution to the original site.
2. **Be Nice:** We're all here to make cool art.

## 🛠️ How to Develop

1. **Fork & Clone** the repo.
2. **Install Dependencies:** `npm install`
3. **Run Locally:** `node server.js`
4. **Test:** Ensure exports still work on your machine.

## 🐛 Reporting Issues

If something breaks, please include:

- Your OS (Windows/Mac/Linux)
- Node.js version
- A screenshot of the error console
