# Mediterranean Drift V3 (WebGL)

A Pen created on CodePen.

Original URL: [https://codepen.io/luis-lessrain/pen/emgBwPj](https://codepen.io/luis-lessrain/pen/emgBwPj).

WebGL flow-field inspired by Mediterranean weather systems.

Particles circulate around evolving low- and high-pressure centers, forming dynamic wind patterns across six seasonal modes, including Mistral, Levante, Tramontana, Sirocco, Summer Calm, and Winter Storm. Color represents wind intensity, while pressure rings and markers reveal the structure of the atmosphere.
