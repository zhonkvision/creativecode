# Opposing Forces - Sonic Collision

A Pen created on CodePen.

Original URL: [https://codepen.io/8binami/pen/NPRwPOd](https://codepen.io/8binami/pen/NPRwPOd).

Two opposing sonic forces collide in real-time. Move your mouse to shape the collision — Left = warm, low, slow frequencies. Right = cold, high, fast frequencies. Where the waves meet, interference patterns emerge visually and sonically. Multi-layered Web Audio engine with 10+ oscillators, binaural collision beats, delay reverb, and reactive canvas particles flowing in opposite directions.
Built with ChiptuneSynth (https://chiptune-synth.8binami.com)
