# Quiet Worlds - Ambient Pixel Piano (C418 vibes)

A Pen created on CodePen.

Original URL: [https://codepen.io/8binami/pen/qEaXYjw](https://codepen.io/8binami/pen/qEaXYjw).

A peaceful Minecraft-inspired ambient piano. Blocky pixel landscape with cubic moon, stars, trees, fireflies and floating clouds. Play the piano with your keyboard (ASDFGHJ) or let Dream mode generate C418-style pentatonic melodies. Every note sends cubic light particles into the night sky. Built with @8bitforge/chiptune-synth. https://chiptune-synth.8binami.com
